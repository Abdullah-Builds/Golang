# Go Learning Examples

This repository contains a collection of small Go example programs organized by topic.

## Structure

The examples are grouped into numbered folders for easy browsing:

- 1_variables
- 2_constants
- 3_for
- 4_if_else
- 5_array
- 6_slices
- 7_map
- 8_range
- 9_functions
- 10_variadic_functions
- 11_closures
- 12_pointers
- 13_struct
- 14_interfaces
- 15_enums
- 16_generics
- 17_goroutines
- 18_channels
- 19_mutex

## How to run

Each folder contains a Go example file. You can run any example with:

```bash
go run main.go
```

If a folder contains a file named `main.go` or another Go source file, run it from that folder.

## Purpose

This repository is intended for learning and practicing core Go concepts through small, focused examples.
